## 🚀 Deploy en Vercel (Método Simple — Static Files)

### Opción A — Vercel Drop (más fácil, 30 segundos)
1. Ve a https://vercel.com/new
2. Selecciona **"Deploy without a framework"** o arrastra la carpeta
3. Sube TODOS los archivos juntos (index.html + todos los .mp4)
4. ¡Listo! Obtienes una URL pública

### Opción B — GitHub + Vercel
1. Crea un repositorio en GitHub
2. Sube `index.html` + todos los archivos `.mp4` a la raíz del repo
3. Ve a vercel.com → New Project → Import from GitHub
4. Framework: **Other**
5. Deploy

### Opción C — GitHub Pages
1. Sube todos los archivos al repo
2. Settings → Pages → Source: main / root
